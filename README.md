## Repository Structure

```text
my-portfolio/
├── README.md
├── .gitignore
└── docs/
    ├── index.html
    ├── resume.html
    ├── 404.html
    ├── assets/
    ├── style.css
    ├── script.js
    ├── robots.txt
    └── sitemap.xml
```

The website is inside `docs/` so GitHub Pages can deploy from the `/docs` folder.

## GitHub Pages Deployment

1. Open repository **Settings**.
2. Go to **Pages**.
3. Select **Deploy from a branch**.
4. Branch: `main`.
5. Folder: `/docs`.
6. Save.
